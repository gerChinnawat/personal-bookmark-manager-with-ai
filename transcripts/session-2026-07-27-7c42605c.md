### ASSISTANT (2026-07-27T04:50:26.360Z)

The `transcripts/` folder is generated automatically, not something you created by hand.

It's produced by a `SessionEnd` hook configured in `.claude/settings.json`: `.claude/hooks/save_transcript.py`. Every time a Claude Code session ends in this project, that script reads the session's `transcript_path` (the raw JSONL conversation log), redacts local file paths, renders it to Markdown, and writes it to `pbm-service/transcripts/session-<date>-<id>.md`. That's why you have several of these files with today's date — one per session.

This is a project-configured logging mechanism (not part of the actual pbm-service application code), so it's safe to `.gitignore` if you don't want these committed, or delete old ones — they're just conversation history snapshots, not something the app depends on.
